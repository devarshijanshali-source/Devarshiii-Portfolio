# Devarshi Janshali — CSE Portfolio

A responsive portfolio website built with HTML5, Bootstrap 5, custom CSS, and JavaScript.

## Included
- Professional profile photo
- B.Tech CSE and Diploma in Information Technology education
- Java Certification Bootcamp certificate
- AI Tools for Engineers certificate
- Skills and contact section
- GitHub link (LinkedIn removed)
- No placeholder projects

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Internet is required for Bootstrap and Google Fonts CDN assets.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.

## Personalize
- Replace the email address in `index.html` with your actual email if needed.
- The GitHub profile link is set to `https://github.com/devarshijanshali-source`.
